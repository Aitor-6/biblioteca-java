# Proyecto Biblioteca

Este proyecto consiste en el diseño e implementación de un sistema de gestión de biblioteca en Java.

## Contenido del proyecto

- Clases Java basadas en un diagrama UML:
  - Libro
  - Autor
  - Ejemplar
  - Socio
  - Renta
  - TipoPenalizacion
  - Genero
- Diagrama UML del sistema incluido en formato PDF

## Estructura

- `src/biblioteca/`: contiene todas las clases del proyecto
- `reto2.drawio.pdf`: diagrama UML de la biblioteca

## Objetivo

Aplicar conceptos de programación orientada a objetos:
- Clases y objetos
- Encapsulación
- Relaciones entre entidades

##  Tecnologías utilizadas

- Java
- UML (Draw.io)
- GitHub
